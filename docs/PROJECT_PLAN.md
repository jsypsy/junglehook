# 정글훅 — 프로젝트 계획

## 한 문단 요약

원버튼 그래플 스윙 하이스코어 게임. **홀드하면 로프가 가장 가까운 앵커에 걸려
흔들리고, 떼면 관성으로 날아간다.** 다음 앵커를 잡으며 오른쪽으로 전진, 거리가
점수다. 놓치면 추락 — 즉사. 게임오버 시 리워드 광고로 이어하기(판당 1회).

설계의 모든 판단 기준은 D-001의 "수익 역산 원칙 5". 확률·아이템 없음(D-004).

## 핵심 루프 (초안 — 프로토타입에서 검증할 것)

```
홀드      가장 가까운 유효 앵커에 로프 연결 → 진자 운동
릴리스    현재 속도 벡터로 발사 (관성 유지)
전진      다음 앵커를 홀드로 잡기 전에 바닥/화면 밖으로 떨어지면 사망
점수      전진 거리(m). 베스트 갱신이 목표
```

**프로토타입에서 답할 질문** (재미의 성패가 여기 달렸다):
1. 앵커 선택 규칙 — "가장 가까운" vs "진행 방향 최적" vs "터치 시점 고정"?
   억울한 죽음(원칙 3)을 만들지 않는 규칙이어야 한다
2. 물리 상수 — 중력·로프 길이·최대 스윙 속도. 손맛의 전부
3. 카메라 — 스크롤 속도와 시야 확보 (다음 앵커가 보여야 판단이 성립)
4. 난이도 곡선 — 앵커 간격·높이 분산을 거리에 따라 어떻게 벌릴 것인가

## 단계

- **Phase 0 — 프로토타입** (지금): mock 어댑터로 핵심 루프만. 위 질문 4개에
  실플레이로 답한다. 재미없으면 여기서 멈추고 방향 재논의 — 이게 이 단계의 존재 이유
- **Phase 1 — 게임 완성**: 사망/이어하기 루프, 점수·베스트, 튜토리얼, 효과음 교체,
  계측 이벤트, 아트 방향 확정
- **Phase 2 — 플랫폼**: 콘솔 미니앱 등록, 실기기 테스트 푸시, 리워드 광고 지면,
  리더보드·공유
- **Phase 3 — 심사·출시**: GRAC 제명 재검색 → 내용설명서 → 등급분류(빌드 동결) →
  콘솔 2단계 검수 → 출시. 절차는 `PLATFORM_PLAYBOOK.md`

## 수익 구조

- **이어하기 리워드 광고** — 주력. `RewardedAdPlacement 'continue'`, 판당 1회
- 지면은 콘솔 발급 후 `src/platform/ait.ts` `AD_GROUP_ID`에 — 빌 때는 보상만 주는 폴백
- 배너는 상단·하단만 허용(모달 금지 정책) — Phase 2에서 판단
- ⚠️ 지면은 23일 무노출 시 삭제 예정 → 출시 임박 전에 발급하지 않는다

## 성공 기준

- Phase 0: "5판 연속으로 자발적으로 다시 하고 싶은가" (사용자 실플레이 판정)
- 출시 후: 콘솔 핵심 지표 — 활성 = 첫 게임 시작, 전환 = 이어하기 광고 시청·재방문
