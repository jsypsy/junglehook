# 출시 관문용 「내용정보별 게임 화면」 4장

콘솔 '앱 출시'에서 [출시하기]를 누르면 `GAME_CONTENT_IMAGES_MISSING`으로 막히며
**게임 주요화면 2종 × (자체등급분류 화면 / 앱인토스 화면) = 4장**을 요구한다(플레이북 §6).
좌우가 픽셀 일치일 필요는 없다 — **같은 게임의 같은 화면 구성**이면 된다.

| 행 | 자체등급분류 열 | 앱인토스 열 |
| --- | --- | --- |
| 1행 (매달리기) | `1-매달리기-자체등급분류.png` (1179×2247) | `1-매달리기-앱인토스.png` (636×1048) |
| 2행 (날아가기) | `2-날아가기-자체등급분류.png` (1179×2247) | `2-날아가기-앱인토스.png` (636×1048) |

- 자체등급분류 열 = GRAC 제출 스크린샷(`assets/grac-스크린샷/`)에서 가져왔다 — 등급을 받은 그 화면이다
- 앱인토스 열 = 콘솔 스토어 스크린샷(`assets/store/`)에서 가져왔다 — 같은 장면을 다른 크기로 렌더한 것
- 둘 다 **B40**(등급본 = 출시본) 화면이고 우하단 표식으로 확인된다
- 내용정보는 전체이용가·해당 없음(NONE)이라, 폭력·공포 같은 항목별 화면이 아니라 **주요 플레이 화면**을 낸다
