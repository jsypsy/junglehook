### 다시 찍는 방법

```
node tools/grac-shots.mjs                       # 헤드리스 크롬 + CDP, 14장 자동 (약 45초)
```

장면은 `src/main.ts`의 DEV 훅 `window.__nara` 위에 스크립트가 심는 `__shot` 도우미(`tp`·`hang`·`wall`·
`chanceCard`·`gauge`·`dash`·`die`)로 만든다. HANDOFF의 "순간이동 캡처 함정" 세 가지(anchor 풀고 옮기기,
`chanceStepM=1e9`, 저장값은 reload)가 스크립트에 반영돼 있다. 잎 배치가 시드 랜덤이라 `hang`은 잎을
찾아 로프를 직접 건다(닿는 잎이 없어 추락하던 첫 시도의 교훈). 벽 장면은 위협 속도를 0으로 두고 잎 기준
250px 뒤에 세워 잡히지 않게 한다. 수동 촬영이 필요하면 `tools/shot-receiver.mjs`(PNG 수신구)를 쓴다.
