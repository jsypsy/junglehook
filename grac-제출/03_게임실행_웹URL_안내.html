1. 심사용 게임 실행 주소

제출한 게임 파일은 웹 게임의 구성 파일(HTML·JavaScript)이라 파일만으로는 실행이 번거로울 수 있습니다. 아래 주소를 웹브라우저 주소창에 입력하시면 설치·로그인·회원가입 없이 즉시 게임이 실행됩니다.

2. PC에서 실제 화면 그대로 확인하는 방법

  1. Chrome 또는 Edge 브라우저로 위 주소를 엽니다.
  2. 키보드 F12를 눌러 개발자도구를 엽니다.
  3. 개발자도구 왼쪽 위의 휴대기기 모양 아이콘을 클릭합니다 (단축키 Ctrl + Shift + M).
  4. 화면 위쪽 기기 목록에서 iPhone 14 Pro 등 아무 스마트폰이나 선택하거나, 직접 크기를 가로 393 × 세로 749로 입력합니다.
  5. F5로 새로고침하면 실제 스마트폰과 동일한 화면이 나타납니다.
개발자도구를 열지 않고 간단히 확인하시려면, 브라우저 창의 가로 폭을 좁게 (400px 내외) 줄이기만 해도 세로 화면 배치로 바뀝니다.

3. 조작 방법 (요약)

  • 시작 화면에서 화면을 탭(클릭)하면 게임이 시작됩니다.
  • 화면 아무 곳이나 꾹 누르면 주인공이 가장 가까운 잎에 로프를 걸고 매달려 흔들립니다. PC에서는 마우스 왼쪽 버튼을 누르고 있으면 됩니다.
  • 손을 떼면 관성으로 앞으로 날아갑니다. 다시 누르면 다음 잎을 잡습니다.
  • 잎을 잡지 못해 화면 아래로 떨어지거나 뒤에서 쫓아오는 벽괴물에 잡히면 게임이 끝납니다. 결과 화면의 [다시 하기]를 탭하면 새로 시작합니다.
  • 「슈퍼 찬스!」 카드가 뜨면 꾹 누른 채 3바퀴 돈 뒤, 화면 위 게이지의 노란 구간에서 손을 떼면 슈퍼 대시가 발동합니다. 카드 안의 애니메이션이 같은 내용을 보여줍니다.

4. 게시한 내용

위 주소에는 등급분류 신청 시 제출한 게임 파일 날아날아_게임빌드.zip과 완전히 동일한 빌드 산출물을 그대로 게시했습니다. 파일이 바이트 단위로 일치하며, 그 근거(SHA-256 해시값)는 별도 문서 「게임물 용량 확인자료」에 기재했습니다.
